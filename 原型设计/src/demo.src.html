三人顺序

胜者排第一位开下一局，其余人保持原顺序；犯规不改变顺序。
例：Isaac → Henry → Hugo
· Isaac 大金 → 顺序不变
· Henry 普胜 → Henry → Isaac → Hugo
· Hugo 普胜 → Hugo → Isaac → Henry
