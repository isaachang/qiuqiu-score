设计说明

为什么比参考记分板更快、更高级

更快的计分

  • 一次点按 = 一次计分。按钮长在每位球员自己的卡片里，点谁的「大金」就是谁赢，告别「先选人再选分」。
  • 零和自动结算。胜方加分的同时负方自动扣分；三人模式支持两家都付 / 仅上家付；犯规 −1 自动给下家 +1。
  • 开球方自动轮转。赢家自动成为下一局开球方并高亮，无需人工记忆。
  • 随时撤销。每次计分底部浮出 Toast 可立即撤销，时间线可左滑修改任意记录。
  • 不解锁也能记。锁屏实时活动 / 灵动岛快捷按钮。

动效语言

  • 滚轮数字：分数按位滚动翻转，弹性曲线收尾。
  • 飞出分值：得失分从数字上方浮起淡出，颜色对应事件。
  • 金球扫光：小金 / 黄金九 / 大金触发卡片金色扫光 + 粒子迸发。
  • 全屏庆祝：大金、黄金九弹出玻璃徽章，九号球旋转入场。
  • 犯规震动：卡片左右震动 + 红色描边闪烁，配合触感反馈。
  • 弹簧交互：所有按钮按下缩放回弹，Tab 透镜、分段控件弹性滑动。

视觉规范

  • Liquid Glass：背景模糊 26–40px + 饱和度 180%、0.5px 高光描边、顶部镜面反光；深色台呢氛围光与真实台球作为折射背景。
